# Arogyama — patient app

Maternal-care app for India: English, Tamil, Hindi; start at any month of pregnancy or after birth; vaccines, 40-day BP watch, breastfeeding and PPIUCD counselling, private mood check and counselling requests, sourced facts everywhere, real notifications. Demo data.

`npm install && npm run dev` · `npm run build` → `dist/index.html` · `npm run test:run` · `npm run i18n` (rebuild Tamil/Hindi from `scripts/i18n/*.tsv`).

Deploys on Vercel with no settings (see `vercel.json`).
